How “The Operations Blueprint” was built

A drafting-table aesthetic, built entirely in code — no images, no frameworks, one HTML file.

StackHTML + CSS + vanilla JS
AssetsInline SVG, self-hosted fonts
Weight~35 KB page + 2 fonts
DependenciesZero

The concept

Ikigai Engine draws up a plan for your operations, so the site is literally a set of drawings: numbered sheets (SHEET 2 OF 6 — SITE SURVEY), figure numbers, a title block, a bill of works, a revision history, and an approval stamp. Every marketing section maps to a drafting convention — the pain list becomes a defect log, before/after becomes REV. A vs REV. B, services become a bill of materials. The conceit does the storytelling; the copy stays plain-spoken.

The drafting paper

The background is four stacked CSS linear-gradients on a fixed element — a fine 12px grid and a bold 96px grid — plus a radial vignette so the edges fall away like a lit drafting table. No image files:

background-image:
  linear-gradient(var(--line) 1px, transparent 1px),
  linear-gradient(90deg, var(--line) 1px, transparent 1px),
  linear-gradient(rgba(127,180,217,.05) 1px, transparent 1px),
  linear-gradient(90deg, rgba(127,180,217,.05) 1px, transparent 1px);
background-size: 96px 96px, 96px 96px, 12px 12px, 12px 12px;

Self-drawing schematics

Every diagram is hand-written inline SVG (documents, lens, gears, gauges). The “drawn by a pen” effect is the classic stroke-dash trick, applied generically: JS measures each path with getTotalLength(), sets stroke-dasharray and stroke-dashoffset to that length (so the stroke is invisible), then an IntersectionObserver flips the offset to 0 when the figure scrolls into view. A per-stroke transition-delay staggers the drawing order so figures assemble piece by piece.

const len = path.getTotalLength();
path.style.strokeDasharray  = `${len} ${len}`;
path.style.strokeDashoffset = len;          // hidden
// on intersect:
path.style.strokeDashoffset = 0;            // draws itself

Flow lines use a second trick — stroke-dasharray: 5 5 with a keyframe animating stroke-dashoffset — to get “marching ants” that make the pipework feel alive. Gears rotate with plain CSS @keyframes on transform-box: fill-box.

Dimension lines & title blocks

The measurement line under the headline is pure CSS: a 1px bar with two tick marks from ::before/::after, and a centered label whose background matches the page so it appears to interrupt the line. Title blocks are just bordered CSS grids in IBM Plex Mono — the font does most of the work.

The approval stamp

The “APPROVED FOR AUTOMATION” stamp pops in with a springy cubic-bezier(.2,1.6,.3,1) scale-down (like a real stamp hitting paper). The worn rubber-ink texture is an inline SVG feTurbulence noise applied as a mask-image — again, zero image files. One gotcha worth stealing: the stamp starts at scale(2.4), and scaled elements enlarge the browser’s scrollable area, which caused horizontal scroll on phones. Fix: overflow: hidden on the section and overflow-x: clip on html.

Micro-interactions

  • Crosshair cursor — two fixed hairlines plus a live X/Y coordinate readout, updated inside requestAnimationFrame. Only enabled for (pointer:fine) devices and hidden until the mouse first moves.
  • Reveal-on-scroll — one reusable .rv class (opacity + 26px rise) driven by a single IntersectionObserver, with .d1/.d2/.d3 delay modifiers.
  • Hover states — defect-log rows tint yellow like highlighter; method cards lift with a long soft shadow.
  • Ticker strip — the three-beat mantra loops in a CSS marquee (two duplicated spans, translateX(-50%)).

Type & accessibility

Two self-hosted faces: Space Grotesk for headlines (geometric, slightly technical) and IBM Plex Mono for all annotations — the pairing sells the “document” feel. Everything respects prefers-reduced-motion (drawing, marquee, and crosshair all disable), diagrams carry role="img" + labels, and the tables use ARIA row/columnheader roles.

Lessons if you build one

  • Pick one metaphor and commit to it in every section — consistency is what makes it feel designed, not decorated.
  • Inline SVG + getTotalLength() gives you “expensive-looking” animation for free, with no libraries.
  • Test on a phone early: transforms, marquees, and absolutely-positioned decorations are the usual horizontal-scroll culprits.
