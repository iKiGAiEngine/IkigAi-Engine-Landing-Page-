Colophon — how “An Essay on Clarity” was set

An exercise in restraint: one serif, one accent color, and typography doing all of the work a hero image usually pretends to do.

StackHTML + CSS + 30 lines of JS
FacesFraunces (variable) & Inter
ColorsPaper, ink, bottle green
Images usedNone

The concept

Four of the five studies in this series shout. This one lowers its voice on purpose — the visual argument is that a company selling clarity should feel like a beautifully set essay: cover, preface, three chapters, an interlude, and an invitation. Every landing-page convention is translated into a print convention. The pain list becomes a numbered litany (i–v, hanging Roman numerals). Before/after becomes a two-column ledger with hairline rules. The founder story becomes “The operator” with a pull quote and a signature line. The CTA is an invitation, full-bleed in ink.

Typography is the whole design

Fraunces is a variable font with an optical-size axis, which is what makes this page feel expensive. With font-optical-sizing: auto, the same file renders the 108px cover line with high-contrast, tight-jointed “display” letterforms, while body text at 18px gets sturdier, more readable shapes. One font file, two personalities.

body{
  font-family:'Fraunces', Georgia, serif;
  font-optical-sizing:auto;   /* opsz 9 → 144 */
  font-weight:380;            /* between Regular and Book */
}

Everything else is spacing discipline: a 660px measure for prose (~62 characters), Inter only for tiny meta labels tracked out to .4em, italics reserved for meaning (never decoration), and a strict scale of hairline rules — 1px solid ink for major boundaries, 16%-alpha hairlines inside components.

Print furniture, rebuilt in CSS

  • Drop cap — the preface opens with a three-line initial via initial-letter: 3, with a float-based fallback inside @supports not (…) for engines that lack it.
  • Chapter numerals — enormous outlined Roman numerals (-webkit-text-stroke over paper-colored fill) that sit position: sticky beside the prose on desktop and collapse above it on phones.
  • Folio & dinkus — the “AN ESSAY ON CLARITY · MMXXVI” line with flanking rules is a flexbox with ::before/::after bars; section breaks use a three-diamond dinkus (✦ ✦ ✦), the classic typographic scene-change.
  • The ledger — before/after rows where the “before” column is struck through in faded ink. On phones the grid collapses to stacked cells that generate their own “BEFORE —” / “AFTER —” labels from CSS ::before content, so the table never squishes.

Motion you barely notice

There are exactly three moving things: a 2px reading-progress bar in green, a slow 1.3s fade-and-rise on scroll (single IntersectionObserver, staggered with delay classes), and the masthead gaining a translucent paper background after 30px of scroll. Buttons animate letter-spacing on hover — text that breathes rather than blocks that bounce. All of it collapses under prefers-reduced-motion.

Why restraint converts

The page still hits every beat a landing page needs — promise, pain, method, proof, bio, ask — but the calm presentation implies the product: this company will make things feel like this page feels. The two CTAs (ink button on paper; paper button on ink at the close) are the only full-contrast elements, so the eye lands on them without a single animation begging for it.

Lessons if you build one

  • A variable font with an optical axis is the cheapest “premium” upgrade in web design — one file, display and text cuts.
  • Pick a measure (55–65ch) first and let it dictate every container width.
  • If you delete an element and the page gets calmer without losing information, it was never design — it was noise.
  • Minimal is unforgiving: with nothing to hide behind, a single bad wrap or crowded margin reads as a defect. Screenshot at phone width relentlessly.
